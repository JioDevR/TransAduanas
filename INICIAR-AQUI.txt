Las pruebas automatizadas backend usan H2 o simulaciones; no cambian la
base MySQL original. No ejecutes schema.sql ni seed.sql para repetirlas.
No uses clean mientras un JAR manual se ejecute desde target.

El ZIP de entrega no incluye node_modules ni claves privadas. En una nueva
extraccion instala dependencias con npm ci en cada interfaz. Se requiere
Java 21, Node 24 y red o caches para descargar las dependencias.
El XML privado del servicio, las herramientas y documentos cargados se
conservan en sus carpetas existentes de Music; no se duplican en el ZIP.

Los logs anteriores conservan sus rutas originales como evidencia historica;
los comandos actuales se ejecutan desde esta nueva carpeta. Una ruta de un
log anterior no significa que Nginx siga usando esa ubicacion.

El plan de 15 pruebas de monitoreo aun requiere el material teorico y las
indicaciones del docente; esta es la base de software preparada para ello.
